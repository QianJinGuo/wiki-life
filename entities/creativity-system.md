# 创造力系统

基于设计思维、创造性问题解决和认知科学的系统化创新方法。

---

## 核心框架: 创造力的三个维度

### 维度一: 设计思维 (Design Thinking)

IDEO和Stanford d.school的方法论 ^[raw/articles/ideo-design-thinking.md]:

**五阶段模型**:

| 阶段 | 核心活动 | 关键问题 |
|------|----------|----------|
| **同理心** | 用户研究、访谈、观察 | 用户真正需要什么？ |
| **定义** | 整合洞察、明确问题 | 我们要解决什么问题？ |
| **构思** | 头脑风暴、概念生成 | 有哪些可能的解决方案？ |
| **原型** | 快速制作、测试想法 | 如何快速验证？ |
| **测试** | 用户反馈、迭代改进 | 什么有效？什么需要改进？ |

**核心原则**:
- 以人为本: 从用户需求出发
- 快速迭代: 快速失败，快速学习
- 视觉化思考: 用草图、原型表达想法
- 跨学科协作: 多元视角碰撞

### 维度二: 创造性问题解决 (CPS)

Osborn-Parnes模型 ^[raw/articles/osborn-creative-problem-solving.md]:

**六步流程**:
1. **目标寻找** (Mess Finding): 识别挑战领域
2. **数据寻找** (Data Finding): 收集相关信息
3. **问题寻找** (Problem Finding): 重新定义问题
4. **想法寻找** (Idea Finding): 生成多种方案
5. **方案寻找** (Solution Finding): 评估和选择
6. **接受寻找** (Acceptance Finding): 制定实施计划

** divergent-convergent 思维**:
```
发散 → 收敛 → 发散 → 收敛 → 发散 → 收敛
(探索)   (选择)   (深化)   (聚焦)   (细化)   (确定)
```

### 维度三: 个体创造力习惯

Csikszentmihalyi的心流研究 ^[raw/articles/csikszentmihalyi-flow-creativity.md]:

**创造力培养的日常习惯**:

| 习惯 | 作用 | 实践方法 |
|------|------|----------|
| **晨间写作** | 清空大脑、捕捉想法 | 每天写3页，不评判 |
| **散步思考** | 促进联想、突破定势 | 每天30分钟无目的散步 |
| **跨界阅读** | 引入新视角 | 每月读一本非专业书籍 |
| **限制练习** | 激发创意 | 给自己设定约束条件 |
| **休息孕育** | 潜意识加工 | 刻意安排放空时间 |

## 头脑风暴技术

### 经典头脑风暴规则

Osborn的4原则 ^[raw/articles/osborn-brainstorming-rules.md]:

1. **延迟评判**: 想法生成阶段不批评
2. **追求数量**: 越多越好，增加好想法概率
3. **自由联想**: 欢迎疯狂想法
4. **组合改进**: 在他人想法上构建

**实施步骤**:
1. 明确问题陈述 (5分钟)
2. 个人静默构思 (5分钟)
3. 轮流分享想法 (15-20分钟)
4. 分类和组合 (10分钟)
5. 评估和选择 (10分钟)

### 进阶技术

**SCAMPER法** (用于改进现有产品):
- **S**ubstitute (替代): 什么可以替代？
- **C**ombine (组合): 可以和什么组合？
- **A**dapt (改造): 如何改造适应？
- **M**odify (修改): 修改什么属性？
- **P**ut to other uses (他用): 其他用途？
- **E**liminate (消除): 什么可以去掉？
- **R**earrange (重组): 重新排列组合？

**六顶思考帽** (De Bono):

| 帽子 | 思维模式 | 问题 |
|------|----------|------|
| 白帽 | 客观事实 | 我们知道什么？ |
| 红帽 | 直觉情绪 | 我的感觉是什么？ |
| 黑帽 | 谨慎批判 | 风险在哪里？ |
| 黄帽 | 乐观价值 | 好处是什么？ |
| 绿帽 | 创造新意 | 新想法是什么？ |
| 蓝帽 | 控制过程 | 下一步做什么？ |

**运用**: 团队轮流"戴"不同帽子讨论问题。

## 实践工具箱

### 创意日常工作流

**早晨 (创意黄金时段)**:
1. **自由写作** (10分钟): 不编辑地写下任何想法
2. **重点项目** (90分钟): 深度创意工作
3. **休息** (20分钟): 完全脱离工作

**下午 (协作和执行)**:
4. **会议和沟通**: 头脑风暴、反馈收集
5. **原型制作**: 快速实现想法
6. **文档整理**: 记录和归档

**晚上 (孕育和恢复)**:
7. **阅读输入**: 跨界知识摄入
8. **放松活动**: 让潜意识工作

### 创意障碍突破

**常见障碍及对策**:

| 障碍 | 症状 | 对策 |
|------|------|------|
| **空白页恐惧** | 不知道如何开始 | 从写垃圾开始，允许自己写得烂 |
| **完美主义** | 反复修改第一段 | 设定时间限制，先完成后完美 |
| **思维定势** | 总是同样想法 | 改变环境、反向思考、随机输入 |
| **倦怠枯竭** | 没有能量和灵感 | 强制休息、切换项目、身体运动 |
| **自我怀疑** | 觉得想法不够好 | 分离自我和作品、寻求反馈 |

**突破练习**:
- **随机词汇法**: 随机选一个词，强制与问题关联
- **专家视角法**: 如果我是XX(乔布斯/达芬奇)，会怎么做？
- **极端约束法**: 如果只能有1个功能/1句话/1美元？

### 创意记录系统

**灵感捕捉**:
- 随身携带捕捉工具 (手机/笔记本)
- 建立"想法仓库"定期回顾
- 每周回顾时评估想法可行性

**项目组织**:
- 活跃项目 (当前正在做的)
- 孵化项目 (暂时搁置但感兴趣的)
- 归档项目 (完成或放弃的)

## 边界条件

**适合**:
- 需要创新的工作 (产品、设计、写作、研发)
- 解决复杂、模糊的问题
- 团队协作创新

**不适合**:
- 标准化、重复性工作
- 时间紧迫、需要快速执行
- 高度规范化、安全关键领域

**创造力的成本**:
- 创新需要时间投入和失败容忍
- 不是所有问题都需要创新解决方案
- 过度发散可能导致无法收敛

## 创造力评估

**个人创造力指标**:

| 维度 | 评估问题 |
|------|----------|
| **流畅性** | 我能产生多少想法？ |
| **灵活性** | 我能从多少角度思考？ |
| **原创性** | 我的想法有多独特？ |
| **精细化** | 我能把想法发展到什么程度？ |

**团队创造力评估**:
- 心理安全感 (能否自由表达)
- 认知多样性 (背景和视角差异)
- 冲突管理 (任务冲突 vs 关系冲突)
