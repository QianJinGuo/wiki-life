# Agent 时代职业建议

> **Original**: Career Advice in the Age of AI Agents — Addy Osmani (Google Chrome/Gemini/Cloud AI 技术 leader，14 年 Google 经验)

Addy Osmani 的核心论点：**AI 擅长任何有"标准答案"的事，你的职业生涯就是那些没有标准答案的部分。** 当 AI 可以完成 70% 的编码工作时，稀缺的不再是"解决问题的能力"，而是"选择什么问题值得解决"的判断力。

## 核心框架：稀缺资源模型

Osmani 提出一个基于稀缺性的职业分析框架：

| 资源类型 | 丰富 | 稀缺 |
|---------|------|------|
| 资本 | ✅ 融资容易 | ❌ 声誉无法快速建立 |
| 时间 | ✅ 充裕 | ❌ 注意力不可再生 |
| 能力 | ✅ 代码生成已有 AI | ❌ 问题选择 + 审美判断 |
| 关系 | ❌ | ✅ 真实的信任关系 |

**关键洞察**：当 AI 让"交付"变得极其廉价时，稀缺的不再是产出速度，而是"选择值得交付什么"的判断力。正如他所说："在 AI 时代，第一次草稿免费，**完成度才是产品**。"^[raw/articles/https-addyosmanicom-blog-career-advice-age-of-agents.md]

## 五大职业策略

### 1. 优化稀缺资源，而非丰厚薪资

Osmani 几乎不为高薪工作。他花在开源上的时间几乎零直接回报，但 **声誉和关系是复利积累的**。

> "资本是充裕的，声誉不是。我可以在几周内融资，但无法在几周内建立声誉。"

### 2. 学会找问题，而非只解决问题

LeetCode 曾是衡量能力的标尺。但 AI 解决了所有"有答案"的问题后，**"发现问题"的能力取代"解决问题"成为真正的竞争优势**。

区分信号：
- **强工程师**带来判断力和直觉
- **普通工程师**带来 prompt

> "判断力是模式匹配，但模式匹配必须通过做真正的活来获得。"

### 3. 刻意练习，而非无脑使用 Agent

真正的实践者不会让 agent 做所有事：
- 挑选几个真正重要的问题，**不用 agent 亲自做一遍**
- **读一千倍的代码**超过你写的
- 把 agent 的每个 diff 当人类 PR 审查
- **每天记录"Agent 建议了错误东西而我识别出来了"的时刻**——这才是品味积累的地方

### 4. 从执行转向指挥

> "自主性是一个设置，不是一个职级；它是一个每个任务可调的开关。"

OSA 模式：**Scope → Define → Calibrate → Verify**
- Scope: 划定任务范围
- Define: 定义"完成"标准
- Calibrate: 校准信任级别
- Verify: 验证结果

### 5. 冲刺最后一英里

Agent 可以快速产出 70% 的功能，但 **最后 30%——调试边缘用例、设计正确架构、培养正确的品味——才是全部的游戏**。

战术：每几个月用最前沿的模型 **完全从头重建一次项目**，避免在前人代码上修修补补。

## 核心格言

| 格言 | 含义 |
|------|------|
| "AI 写的不代表你该信任它" | 验证不是证据，Agent 给自己打的分不算 |
| "你的名字在 commit 上" | "AI 干的"不是免责声明 |
| "第一次草稿免费，完成度才是产品" | 中位数输出是 lazy prompt 的结果，个性化价值在超出中位数的地方 |
| "注意力不可再生" | AI 产出无限，但你的注意力不会自动补充 |

## 与相关理念的联系

- **[[concepts/deliberate-practice|刻意练习]]**：Osmani 强调的"不用 Agent 亲自做"与 Anders Ericsson 的刻意练习理论高度一致——真正的成长发生在有挑战、有反馈的重复中，而非自动化替代
- **Bitter Lesson**：引用 Rich Sutton 的 bitter lesson——通用方法 + 算力扩展胜出手工调优；**问题选择**是 bitter lesson 的职业生涯应用版
- **注意力管理**：注意力不可再生的观点与专注/心流类理念一致

## 局限性

- **面向资深工程师**：junior 在没有足够的"问题发现经验"时，可能仍然需要大量"解决问题"的练习来建立判断力
- **Google 光环效应**：Osmani 的声誉积累路径（开源 + 大公司背书）对独立开发者或非英语环境不完全适用
- **短期 vs 长期矛盾**：刻意练习不依赖 Agent 的策略在竞争激烈的短期市场可能处于劣势
