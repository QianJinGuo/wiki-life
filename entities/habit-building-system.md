# 习惯养成系统

基于行为科学研究的系统化习惯构建方法论。

---

## 核心框架: 习惯回路 + 环境设计

### 习惯回路的神经科学基础

习惯形成的神经机制: 基底神经节通过"提示→行为→奖励"回路自动化行为 ^[raw/articles/atomic-habits-james-clear.md]。

**四个定律**:
1. **让它明显** (提示可见)
2. **让它有吸引力** (多巴胺预期)
3. **让它容易** (减少摩擦)
4. **让它满足** (即时奖励)

### 环境设计三原则

来自选择架构理论 ^[raw/articles/nudge-thaler-sunstein.md]:

| 原则 | 操作 | 例子 |
|------|------|------|
| **减少摩擦** | 让好习惯更容易 | 运动服睡前摆好 |
| **增加提示** | 让触发器可见 | 吉他放客厅中央 |
| **消除诱惑** | 让坏习惯更难 | 手机放另一个房间充电 |

## 实操工具箱

### 1. 习惯堆叠公式

> "在我[当前习惯]之后，我将[新习惯]。"

**边界条件**: 
- ✅ 锚点习惯必须每天发生
- ✅ 新习惯要在5分钟内完成
- ❌ 不要堆叠超过3个新习惯

### 2. 两分钟规则

任何新习惯的开始版本必须在2分钟内完成：
- "读30分钟" → "读1页"
- "跑步5公里" → "穿上跑鞋出门"
- "写1000字" → "打开文档写一句话"

**目的**: 降低启动阻力，建立身份认同("我是运动的人")。

### 3. 习惯追踪器设计

**核心指标**: 
- 连续性(不要断链)
- 而非完美(允许偶尔跳过)

**格式**:
```
习惯: _______
追踪方式: 日历打勾 / App记录 / 纸质表格
复盘频率: 每周日检查
恢复规则: 如果断了2天，第3天必须恢复
```

## 失败模式与修复

| 失败信号 | 可能原因 | 修复策略 |
|---------|---------|---------|
| 总是忘记 | 提示不够明显 | 改变环境，让触发器无法忽视 |
| 开始困难 | 启动阻力太大 | 两分钟规则，降低初始成本 |
| 坚持几天放弃 | 期望过高 | 关注一致性而非强度 |
| 感到厌烦 | 缺乏奖励 | 增加即时反馈或游戏化元素 |

## 边界条件

**适合**:
- 行为自动化(健身、阅读、冥想)
- 重复性技能训练
- 日常作息建立

**不适合**:
- 需要深度思考的创新工作
- 复杂决策过程
- 人际关系技能(需要情境适应)

---

## 进阶: 身份认同改变

James Clear的核心观点: 目标不是跑马拉松，而是成为"跑步的人"。

**身份转变三问**:
1. 我想成为什么样的人?
2. 那种人会做XX事吗?
3. 我今天做了一个小而具体的证据吗?
