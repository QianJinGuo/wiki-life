# 时间管理系统

基于GTD、时间块和深度工作理论的系统化时间投资方法。

---

## 核心框架: 时间管理的三个层次

### 层次一: 捕捉与组织 (GTD)

Allen的Getting Things Done框架 ^[raw/articles/allen-getting-things-done.md]:

**五步法**:
1. **捕捉** (Capture): 所有任务进入inbox，大脑不记
2. **理清** (Clarify): 任务是否可行？下一步行动？
3. **整理** (Organize): 分类到项目/上下文/日程
4. **回顾** (Reflect): 每周回顾系统
5. **执行** (Engage): 根据情境选择任务

**关键原则**:
- 2分钟规则: 2分钟能完成的立即做
- 下一步行动: 每个项目必须有具体的下一步
- 每周回顾: 清空inbox + 回顾项目 + 更新清单

### 层次二: 时间分配 (时间块)

Cal Newport的时间块方法 ^[raw/articles/newport-time-block-planner.md]:

**实施步骤**:
1. **规划块**: 每天开始前分配时间块
2. **任务块**: 固定时长专注单一任务
3. **缓冲块**: 处理意外和过渡
4. **收尾块**: 日终总结和明日规划

**模板示例**:
```
08:00-09:00 深度工作 (写作)
09:00-09:30 缓冲 (邮件处理)
09:30-11:00 深度工作 (编程)
11:00-12:00 会议
12:00-13:00 午餐
13:00-14:00 浅层工作 (行政)
14:00-16:00 深度工作 (设计)
16:00-17:00 缓冲 + 明日规划
```

### 层次三: 专注执行 (深度工作)

Newport的深度工作理论 ^[raw/articles/newport-deep-work.md]:

**深度工作定义**: 无干扰的专注活动，创造新价值

**四种哲学**:
| 哲学 | 描述 | 适合人群 |
|------|------|----------|
| **隐修式** | 长时间完全隔离 | 学者、作家 |
| **双峰式** | 深度/浅层时间分明 | 有固定职责的人 |
| **节奏式** | 每天固定深度时段 | 大多数知识工作者 |
| **记者式** | 随时抓住碎片时间 | 日程不可控者 |

**推荐**: 大多数人选"节奏式"，每天2-4小时固定深度时段。

## 实践工具箱

### 日计划模板

**晨间规划 (5分钟)**:
1. 回顾日历和今日必做
2. 确定1-3个最重要的任务 (MIT)
3. 分配时间块

**晚间复盘 (5分钟)**:
1. 完成了什么？
2. 什么打断了计划？
3. 明日调整什么？

### 注意力管理矩阵

| | 高价值 | 低价值 |
|--|--------|--------|
| **高认知负荷** | 深度工作 | 学习新技能 |
| **低认知负荷** | 规划思考 | 浅层工作 |

**策略**:
- 深度工作: 精力充沛时 + 无干扰环境
- 浅层工作: 碎片时间 + 批量处理

### 打断管理

**外部打断**:
- 通知管理: 关闭非必要通知
- 邮件策略: 固定时间查看 (如每天11am/4pm)
- 沟通规则: 告知同事深度工作时段

**内部打断**:
- 冲动记录: 有想法先记下，不打断当前任务
- 番茄工作法: 25分钟专注 + 5分钟休息
- 环境设计: 手机放另一个房间

## 进阶策略

### 精力管理配合

**昼夜节律优化**:
1. 识别个人黄金时段 (通常是起床后2-4小时)
2. 将最难任务安排在黄金时段
3. 午后安排低认知负荷任务

**能量循环**:
- 90分钟专注 + 20分钟休息 (符合超日节律)
- 每工作50分钟强制休息5分钟

### 周度规划系统

**周日规划 (30分钟)**:
1. 回顾上周完成情况
2. 查看下周日历和截止日期
3. 确定3个周目标
4. 分配时间块到日历

**周五复盘 (15分钟)**:
1. 清空inbox
2. 更新项目状态
3. 计划下周
4.  shutdown ritual (告诉大脑工作结束)

## 边界条件

**适合**:
- 知识工作者、创意工作者
- 需要深度思考的工作
- 可自主安排时间的环境

**不适合**:
- 高度协作、随时响应的岗位 (如客服、急诊)
- 需要频繁切换上下文的工作
- 严格流水线式的工作

**常见失败模式**:
1. 过度规划: 计划时间 > 执行时间
2. 忽视缓冲: 没有预留处理意外的时间
3. 完美主义: 一天没按计划就放弃
4. 忽视身体: 长期不睡觉/不运动追求效率
