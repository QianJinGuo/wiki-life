# 字节跳动（豆包/Coze团队）面试策略

**难度级别**：⭐⭐⭐⭐（竞争激烈）
**准备周期**：建议4-6周

## 🔍 团队背景调研

### 豆包（Doubao）

- **产品**：豆包APP、豆包大模型API
- **技术栈**：自研模型 + 开源模型微调

- **定位**：AI Bot开发平台（对标GPTs）

- **技术挑战**：
  - 多模型适配（GPT/Claude/豆包）
  - 高并发Bot运行

- **语言**：Python（主）、Go（后端）、TypeScript（前端）
- **框架**：自研 + LangChain参考
- **基础设施**：K8s、自研中间件
- **AI栈**：PyTorch、vLLM、自研推理框架

## 🎯 核心技术考察点

### 1. LLM基础（必问）

**高频问题**：
1. **Transformer架构**
   - Q: 解释Multi-Head Attention机制
   - A要点：QKV计算、多头并行、位置编码
   
2. **生成策略**
   - Q: Temperature vs Top-p vs Top-k
   - A要点：采样策略对输出多样性的影响
   
3. **上下文窗口**
   - Q: 如何处理长文本？
   - A要点：RAG、摘要、滑动窗口、Longformer

4. **模型微调**
   - Q: LoRA原理及适用场景
   - A要点：低秩分解、参数效率、与Full FT对比

**准备建议**：
- 能画Transformer架构图
- 能推导Attention公式
- 了解豆包模型技术报告（如有公开）

---

### 2. Agent架构（重点）

**必考问题**：

**Q1: 设计一个客服Agent系统**
```
考察点：
- 如何分解任务（意图识别→知识检索→回答生成）
- 多轮对话管理（State维护）
- 知识库更新机制
- 异常处理（答不上来时）
- 评估指标

优秀回答结构：
1. 需求分析（场景、用户、约束）
2. 架构图（组件、数据流）
3. 关键技术选型（为什么选X）
4. 风险与优化（延迟、成本、准确性）
```

**Q2: Coze平台的技术难点**
```
考察点：
- 多租户隔离
- 插件安全（沙箱机制）
- 高并发Bot运行
- 模型路由（根据任务选模型）

思考角度：
- 架构：微服务 vs 单体
- 安全：代码执行沙箱
- 性能：缓存、批处理
- 成本：模型选择策略
```

**Q3: ReAct vs Plan-and-Execute**
```
对比维度：
- 适用场景
- 延迟差异
- 准确性
- 可解释性

加分回答：
- 混合策略（先Plan，再ReAct执行）
- 实际踩坑经验
```

### 3. 工程能力

**系统设计题**：

**题目：设计Agent运行平台**
要求：
- 支持用户上传自定义Agent
- 支持工具调用（搜索、代码执行）
- 支持多轮对话
- 10万QPS

**回答框架**：
```
1. 需求拆解
   - 功能需求：Agent管理、执行、监控
   - 非功能：性能、安全、可用性

2. 核心架构
   - API Gateway
   - Agent调度器
   - 沙箱执行环境
   - 上下文存储（Redis/DB）
   - 模型推理服务

3. 关键设计
   - 沙箱：Docker/Kata Container
   - 状态：State Machine
   - 扩展：Worker Pool

4. 优化
   - 缓存相似查询
   - 模型批处理
   - 异步执行
```

**代码题**：
- 难度：LeetCode Medium-Hard
- 类型：字符串处理、设计类、并发
- 示例：实现LRU缓存、生产者消费者

## 💰 薪资谈判

### 字节薪资结构
- **基础工资**：月薪 × 15-18（年薪）
- **签字费**：可谈（通常1-3个月）
- **股票**：RSU，4年归属
- **绩效**：年终奖浮动

### Agent岗位市场参考
- **P5（1-3年）**：40-60万
- **P6（3-5年）**：60-90万
- **P7（5年+）**：90-150万

### 谈判策略
1. **了解行情**：多面几家拿offer
2. **展示价值**：强调Agent项目经验
3. **总包思维**：基础+签字费+股票综合考虑
4. **灵活让步**：如果现金给不了，要更多股票
