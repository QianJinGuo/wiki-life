# Atomic Habits: 习惯养成的实证方法

**来源**: James Clear (2018). *Atomic Habits: An Easy & Proven Way to Build Good Habits & Break Bad Ones*. Penguin Random House.
**归档日期**: 2025-06-09

## 核心概念

### 1. 微小变化的巨大力量

**复利巨大**: 如果你每天进步1%，一年后你会进步40倍。如果每天退步1%，一年后你将接近零。

**成等反差**: 大多数人实现的穿越不是由一个勇敢的行动，而是通过每日1%的改进积累而来。

### 2. 习惯回路

大脑建立回路的四步:

1. **Cue (提示)**: 触发行为的信号
2. **Craving (渴望)**: 对变化的欲望
3. **Response (响应)**: 实际行动
4. **Reward (奖励)**: 获得的好处，强化回路

### 3. 习惯养成的四定律

**第一定律: 让它明显 (Make it Obvious)**

- 填写句子: "每当[X]时候，我将[Y]"
- 环境设计: 让好习惯的触发器可见，坏习惯隐藏
- 叠加习惯: 将新习惯与已有习惯绑定

**第二定律: 让它有吸引力 (Make it Attractive)**

- 诱惑绑定: 将需要做的与想做的绑定
- 社群动力: 加入正向社群
- 心态转变: "我必须"改为"我想要"

**第三定律: 让它容易 (Make it Easy)**

- 最小努力原则: 减少开始的摩擦
- 两分钟规则: 当习惯变成2分钟，你会更容易开始
- 环境优化: 为正向行为创造有利环境

**第四定律: 让它满足 (Make it Satisfying)**

- 即时奖励: 给习惯绑定即时正向反馈
- 习惯追踪: 记录每一次成功
- 缺亏戴德：完成习惯不要打断连续性

### 4. 身份转变

**从目标到身份**:
- 不要说"我想成为跑者"
- 要说"我就是跑者，只是在学习"

**两个问题清单**:
1. 哪种人会实现我的目标?
2. 那种人会做什么?

## 实践应用

### 实施意图模板

```
每当[现有习惯] 之后，
我将[新习惯] 在 [ 具体地点 ] 。
例如: 每当下班到家之后，
        我将立即换上运动服去跑步。
```

### 环境设计清单

**增加好习惯**:
- [ ] 把健身服放在床上
- [ ] 把水果放在桌上
- [ ] 把书放在沙发旁

**减少坏习惯**:
- [ ] 手机充电在另一个房间
- [ ] 把零食放在看不见的地方
- [ ] 浏览器通知全部关闭
