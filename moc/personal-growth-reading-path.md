# 人生成长主题地图

> 这不是清单，是**阅读顺序**。按"地基 → 习惯 → 系统 → 高阶"4 层递进。如果你只读一遍，请按此顺序。

## 第 1 层：地基（认知模型，决定一切）

最先读，因为它们是其他所有内容的前置：

1. [[concepts/first-principles-thinking|第一性原理思考]] — 拆分到不可拆的最小单元再重组
2. [[concepts/systems-thinking|系统思维]] — 找到杠杆点而不是症状
3. [[concepts/compound-effect|复利效应]] — 解释为什么"小坚持"能改变人生
4. [[entities/decision-frameworks|决策框架]] — Musk / Tim Cook / Jensen Huang 三种实操决策法

**为什么先读这 4 个**：没有这层认知模型，下面的"方法论"会被当作鸡汤而非工程。

## 第 2 层：习惯（每天的执行系统）

读完地基后，第二步是搭习惯——所有大目标都靠日常习惯堆出来：

5. [[entities/self-discipline|自律系统]] — 意志力管理 + 系统设计代替依赖意志
6. [[entities/habit-building-system|习惯养成系统]] — 习惯回路 + 环境设计 + 微习惯
7. [[entities/time-management-system|时间管理系统]] — 4 象限 + 时间块 + 精力管理
8. [[concepts/ego-depletion|意志力耗损]] — 意志力是有限资源，必须靠系统而非毅力

**为什么是第 2 层**：第 1 层决定方向，第 2 层决定执行——没有习惯，再好的认知也只是空谈。

## 第 3 层：系统（身/心/财/关系四大支柱）

习惯运转后，第三步是搭起四大生活子系统：

9. [[entities/health-optimization-system|健康优化系统]] — 睡眠 / 运动 / 饮食三件套
10. [[entities/mental-wellness|心理健康]] — CBT + ACT + MBSR 实证方法
11. [[entities/personal-finance|个人理财]] — 4% 原则 / 应急金 / 资产配置
12. [[entities/relationship-maintenance|关系维护]] — NVC 沟通 + 冲突解决 + 长期亲密关系

**为什么是第 3 层**：身心财关系是"独立可崩溃单元"——任何一个崩，其他全部受影响。

## 第 4 层：高阶（认知/沟通/创造力放大器）

四大系统稳定后，第四层是放大器：

13. [[entities/cognitive-enhancement|认知增强]] — 元认知 / 学习如何学习 / 阅读法
14. [[entities/communication-skills|沟通技巧]] — 表达 / 倾听 / 影响力的实操方法
15. [[entities/creativity-system|创造力系统]] — 跨界连接 / 类比思维 / 卡片盒方法
16. [[entities/career-development|职业发展]] — T 型人才 / 行业选择 / 副业系统

**为什么是第 4 层**：这层是"乘数效应"——前 3 层是 1，这层是 ×10。没有前 3 层，乘多少都是 0。

## 反 anti-pattern：禁止跳过地基

最常见的错误是直接从第 3 层（系统）开始读——结果是：
- 学了一堆方法论但用不下去（缺第 1 层认知）
- 知道该做却做不到（缺第 2 层习惯）

→ 如果时间只够读 3 篇，按顺序读 `first-principles-thinking → self-discipline → habit-building-system`。这 3 篇是全 wiki 的最小必读集。
