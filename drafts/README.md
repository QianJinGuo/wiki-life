# drafts/ — 对外输出层

知识库的终局是输出，不是收藏。本目录收集从 wiki 实体反向蒸馏的对外文章草稿。

## 使用规范

- 每篇 draft：2-3K 字独立成文
- 来源：100% 引用本 wiki 内部 entity/concept（不引入新源）
- frontmatter 必须包含 `status: draft | review | published | archived`
- 发布后追加 `published_url:` 和 `published_at:`，状态切到 `published`
